# Kebijakan Privasi HitungIn

_Berlaku sejak: [TANGGAL]_

HitungIn ("aplikasi") adalah aplikasi pencatat keuangan pribadi yang dibuat oleh
[NAMA PENGEMBANG]. Kebijakan ini menjelaskan data apa yang diproses aplikasi dan bagaimana.

## Data keuangan kamu tetap di HP-mu

- Transaksi, dompet, kategori, budget, tagihan, catatan, dan PIN **disimpan hanya di perangkatmu**
  dalam database terenkripsi. HitungIn tidak punya server dan tidak mengirim data ini ke mana pun.
- Tidak perlu akun atau login.
- PIN disimpan dalam bentuk yang tidak bisa dibaca kembali (hash) di penyimpanan aman perangkat.
  Buka kunci dengan sidik jari/wajah diproses oleh sistem Android; aplikasi tidak menerima data biometrik.

## Backup & ekspor

Backup dan ekspor CSV hanya dibuat saat kamu memintanya, lalu disimpan ke lokasi yang kamu pilih
(mis. penyimpanan HP atau Google Drive milikmu). File backup dienkripsi dengan kata sandi
yang kamu tentukan. Kami tidak bisa mengakses file tersebut.

## Notifikasi

Pengingat tagihan dijadwalkan di perangkat (notifikasi lokal). Tidak ada data yang dikirim
untuk keperluan ini.

## Iklan (versi gratis)

Versi gratis menampilkan iklan dari **Google AdMob**. Google dapat mengumpulkan data seperti
ID iklan perangkat, informasi perangkat, perkiraan lokasi dari alamat IP, dan interaksi dengan
iklan untuk menampilkan serta mengukur iklan. Jika diwajibkan di wilayahmu, aplikasi meminta
persetujuanmu terlebih dahulu, dan kamu bisa mengubahnya kapan saja.
Data transaksi keuanganmu **tidak** dibagikan ke penyedia iklan.

Selengkapnya: https://policies.google.com/technologies/ads
Kamu dapat mereset atau menghapus ID iklan di Setelan Android → Google → Iklan.

Pengguna **HitungIn Pro** tidak melihat iklan.

## Pembelian

Pembelian HitungIn Pro diproses oleh **Google Play**. Kami tidak menerima data kartu atau
pembayaranmu; aplikasi hanya menerima konfirmasi pembelian dari Google Play.
Lihat: https://policies.google.com/privacy

## Anak-anak

HitungIn tidak ditujukan untuk anak di bawah 13 tahun.

## Menghapus data

Semua data bisa dihapus dengan menghapus data aplikasi atau meng-uninstall HitungIn.
File backup yang kamu simpan sendiri perlu dihapus secara manual.

## Perubahan

Kebijakan ini dapat diperbarui. Versi terbaru selalu tersedia di halaman ini.
