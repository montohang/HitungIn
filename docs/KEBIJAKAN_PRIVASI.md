# Kebijakan Privasi HitungIn

> Sumber tayang: `appgratis` repo → `pages/hitungin/privacy-policy.vue` (https://appgratis.id/hitungin/privacy-policy). File ini salinan teks untuk rujukan; ubah keduanya bersamaan.

## 1. Data yang Dikumpulkan
HitungIn adalah aplikasi pencatat keuangan pribadi yang bekerja offline. Aplikasi hanya menyimpan data yang Anda masukkan sendiri, seperti nama panggilan, transaksi, dompet, kategori, budget, tagihan dan cicilan, utang-piutang, patungan, target tabungan, aset untuk kekayaan bersih, dan catatan.

Tidak perlu akun atau login. HitungIn tidak memiliki server untuk menampung data Anda dan tidak mengumpulkan data analitik penggunaan aplikasi.

## 2. Penyimpanan Data
Semua data keuangan disimpan hanya di perangkat Anda dalam database terenkripsi. Data ini tidak pernah dikirim ke server kami atau ke pihak lain.

PIN tidak disimpan apa adanya — hanya dalam bentuk hash yang tidak bisa dibaca kembali. Buka kunci dengan sidik jari atau wajah diproses oleh sistem Android; aplikasi tidak menerima data biometrik Anda.

## 3. Backup, Backup Otomatis & Ekspor
Backup manual dan ekspor (Excel, PDF, CSV) hanya dibuat saat Anda memintanya, lalu disimpan ke lokasi yang Anda pilih sendiri, misalnya penyimpanan HP atau Google Drive milik Anda.

Jika Anda mengaktifkan backup otomatis, aplikasi membuat backup terjadwal (umumnya sekali sehari saat HP mengisi daya) ke folder yang Anda pilih dan menyimpan beberapa salinan terakhir. Akses ke folder tersebut diberikan lewat pemilih folder Android dan dapat dicabut kapan saja dengan mematikan backup otomatis.

Semua file backup dienkripsi dengan kata sandi yang Anda tentukan. Untuk backup otomatis, kata sandi disimpan terenkripsi di penyimpanan aman perangkat dan hanya dapat ditampilkan setelah memasukkan PIN. Kami tidak dapat mengakses file backup maupun kata sandinya.

## 4. Scan Struk
Fitur scan struk memakai kamera atau galeri melalui pemindai dokumen Google Play Services. Teks pada struk dibaca langsung di perangkat menggunakan Google ML Kit; foto struk tidak dikirim ke server kami dan tidak disimpan oleh HitungIn setelah dibaca.

Sesuai ketentuannya, Google ML Kit dapat mengirim data diagnostik dan statistik penggunaan API yang tidak berisi isi struk kepada Google untuk menjaga kualitas layanannya. Selengkapnya: [ketentuan Google ML Kit](https://developers.google.com/ml-kit/terms).

## 5. Foto untuk Tampilan
Jika Anda memilih foto dari galeri untuk latar widget atau untuk saran warna tema, foto tersebut diproses dan disimpan hanya di perangkat Anda. Foto latar widget tidak ikut dalam file backup dan tidak dikirim ke mana pun.

## 6. Notifikasi
Pengingat tagihan, cicilan, utang-piutang, dan status backup dijadwalkan langsung di perangkat (notifikasi lokal). Tidak ada data yang dikirim untuk keperluan ini.

## 7. Iklan (Versi Gratis)
Versi gratis menampilkan iklan dari Google AdMob. Google dapat mengumpulkan data seperti ID iklan perangkat, informasi perangkat, perkiraan lokasi dari alamat IP, serta interaksi dengan iklan untuk menampilkan dan mengukur iklan. Jika diwajibkan di wilayah Anda, aplikasi meminta persetujuan terlebih dahulu, dan pilihan itu bisa diubah kapan saja.

Data transaksi keuangan Anda **tidak** dibagikan ke penyedia iklan. Selama masa promo, fitur Pro dapat digunakan gratis namun iklan tetap tampil; pemilik HitungIn Pro tidak melihat iklan. Selengkapnya: [kebijakan iklan Google](https://policies.google.com/technologies/ads). ID iklan dapat direset atau dihapus di Setelan Android → Google → Iklan.

## 8. Pembelian
Pembelian HitungIn Pro diproses oleh Google Play. Kami tidak menerima data kartu atau pembayaran Anda; aplikasi hanya menerima konfirmasi pembelian dari Google Play. Lihat [kebijakan privasi Google](https://policies.google.com/privacy).

## 9. Izin Perangkat
Aplikasi meminta atau menggunakan izin berikut:

- Notifikasi — pengingat tagihan, utang-piutang, dan backup (dijadwalkan di perangkat)
- Mulai saat perangkat dinyalakan — menjadwalkan ulang pengingat dan backup otomatis setelah HP restart
- Biometrik — membuka aplikasi dengan sidik jari atau wajah (opsional)
- Internet & status jaringan — hanya untuk iklan, pembelian melalui Google Play, dan komponen layanan Google
- ID iklan — untuk iklan di versi gratis
- Tugas latar belakang — menjalankan backup otomatis terjadwal
- Kamera — tidak diminta langsung; foto struk diambil lewat pemindai dokumen atau aplikasi kamera sistem

## 10. Berbagi Data
Kami tidak menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak ketiga. Data hanya keluar dari perangkat jika Anda sendiri yang membagikannya (misalnya kartu rekap, tagihan patungan, atau file ekspor melalui menu Bagikan Android), atau dikumpulkan oleh layanan Google untuk iklan, pembelian, dan ML Kit seperti dijelaskan di atas.

## 11. Keamanan Data
Data disimpan terenkripsi dan aplikasi bisa dikunci dengan PIN atau biometrik. Namun, tidak ada sistem yang sepenuhnya aman. Anda bertanggung jawab menjaga keamanan perangkat, PIN, dan kata sandi backup Anda.

## 12. Hak Pengguna & Penghapusan Data
Anda dapat melihat, mengubah, mengekspor, atau menghapus data kapan saja melalui fitur di aplikasi. Seluruh data dapat dihapus dengan menghapus data aplikasi atau meng-uninstall HitungIn. File backup dan ekspor yang Anda simpan sendiri, termasuk salinan backup otomatis di folder pilihan Anda, perlu dihapus secara manual.

## 13. Anak-anak
HitungIn tidak ditujukan untuk anak di bawah 13 tahun.

## 14. Perubahan Kebijakan
Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Versi terbaru selalu tersedia di halaman ini, dan perubahan signifikan akan diinformasikan melalui pembaruan aplikasi.
